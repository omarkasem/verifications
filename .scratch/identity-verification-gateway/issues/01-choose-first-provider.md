# Choose the First Verification Provider

## Question

Which of Didit, Stripe Identity, or Persona is the best first provider for V1 after comparing supported countries, identity and age claims, hosted buyer flows, webhook behavior, test mode, pricing, data handling boundaries, and API constraints relevant to WordPress and WooCommerce?

## Resolution

Choose **Didit** as the first Verification Provider for V1.

See [Research: Choose the First Verification Provider](../research/01-first-provider-comparison.md) for the comparison, rationale, risks, and provider-contract constraints.
